# Device Notes

This folder stores device-specific setup notes and change logs.

Goal:

- keep track of changes made on a specific machine (especially the notebook)
- keep the main project steps reproducible on both notebook and desktop

Convention:

- create a new markdown file per change
- name it `YYYY-MM-DD-short-title.md`
- include:
  - what changed
  - why it changed
  - exact commands / settings used
  - any rollback steps
