# Bell Ringer 포스터 문구 초안

## 01 개요

- 눈을 감고 시야를 차단한 상태에서 진행하는 몰입형 감각 게임
- 종소리와 LED 단서를 따라 이동하고, 패드 위치/회전으로 이명을 정화하는 구조
- 머리 회전, 패드 위치, 패드 회전, LED 빛, 진동 피드백을 하나의 플레이 체계로 결합

짧은 설명 문장:

> 시야를 차단한 상태에서 소리, 빛, 진동을 따라 종을 찾고 이명을 정화하는 감각 중심 게임이다.

## 02 배경 및 목적

### 배경

> 시각을 줄이면 방향과 존재를 파악하는 기준이 소리, 빛, 진동으로 이동한다.  
> 이 프로젝트는 접근성 해결보다, 눈을 감았을 때 발생하는 낯설고 독특한 감각 경험 자체를 게임으로 만들고자 한 시도에서 출발했다.

### 목적

> 종, 비, 벽, 이명을 각기 다른 소리와 빛 패턴으로 구분하고, 머리 회전과 패드 위치/회전 입력을 결합하여 시야 차단 상태에서도 진행 가능한 감각 중심 플레이를 구현한다.

### 기술 반영

- ArUco 기반 패드 위치 추적
- 카메라 기반 패드 yaw + IMU 기반 pitch/roll 결합
- ESP32-S3 2대, MPU-9250 2개, WS LED 2장 사용
- 폐안 상태에서 구분이 쉬운 색상을 직접 선정 후 적용

## 03 내용

### 게임 플레이 흐름

1. 준비  
   눈을 감고 주변 소리에 집중하며 감각 전환을 시작한다.
2. 종 추적  
   멀리서 들리는 종소리를 따라 방향과 거리를 찾는다.
3. 비바람  
   비와 바람이 종소리를 가리며 청각 분리를 유도한다.
4. 종 바라보기  
   종의 위치가 계속 이동하고, 시선을 고정하여 위치를 확인한다.
5. 이명 정화  
   패드 위치와 회전을 맞춰 일반 이명을 정화한다.
6. 보스 이명  
   더 강하고 불안정한 이명을 이동 경로에 맞춰 추적 정화한다.
7. 숲 엔딩  
   모든 이명을 정화한 뒤 평화로운 숲 소리와 함께 엔딩으로 이어진다.

### 색상 체계

- 종: 초록
- 벽: 시안
- 비: 딥 블루
- 이명: 바이올렛
- 패드: 코드 기준 오렌지

### 기술 동작 흐름

- Head IMU: 머리 yaw / pitch / roll 입력
- Pad IMU: 패드 pitch / roll 입력
- ArUco Camera: 패드 위치 + yaw 입력
- Unity Logic: 상태 판정, 거리 계산, 이벤트 제어
- Feedback Output: 공간 음향, LED 패턴, 진동 출력

## 04 결과

### 권장 배치

- VR/폐안 장비 사진 1장
- ArUco 마커가 부착된 게임 패드 사진 1장
- 인게임 장면 1장
- 필요 시 시스템 구성도 또는 테스트 장면 1장

### 짧은 결과 문장

> 시각 대신 소리, 빛, 진동을 중심으로 한 플레이 구조를 구현했으며, 하드웨어와 인게임 시스템을 연동한 감각 중심 프로토타입을 제작하였다.
